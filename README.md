# 👋 Hi, I'm Alex

**Network Engineer | Python & Network Automation**

I'm a Network Engineer with 4.5 years of experience in the industry. About a year into my first IT job, I kept running into repetitive, time-consuming tasks that I knew could be automated, and that's what got me into Python and network automation. My first script checked 50+ UniFi controllers for offline access points, built a report, and posted it through a Microsoft Teams webhook to our NOC channel so engineers could review it.

## 🔧 What I'm building now
- **Automation platform:** Self-hosted [Windmill](https://www.windmill.dev/) (Docker Compose behind Nginx Proxy Manager) that runs my team's report scripts and flows
- **FortiAP alerting:** A Windmill flow that checks multiple FortiGates for offline FortiAPs and alerts a Teams channel
- **Config generation:** Python that turns spreadsheet channel plans into FortiGate CLI for per-AP radio overrides on large wireless deployments
- **Outage reconciliation:** A pipeline that matches offline APs against open trouble tickets so nothing goes untracked
